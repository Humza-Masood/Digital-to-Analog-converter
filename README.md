# 3-bit Digital-to-Analog Converter

Designed, simulated, and physically implemented a 3-bit digital-to-analog converter (DAC) using an LMC662 operational amplifier, binary-weighted resistor network, and unity-gain buffers.

The circuit converts 3-bit digital inputs into eight discrete analog voltage levels across a 0–5V output range.

All eight digital input combinations were experimentally tested using Digilent Analog Discovery, with the following measured performance:

- **Maximum differential non-linearity:** 0.048 LSB
- **Offset error:** 38 mV
- **Gain error:** −68 mV

The repository contains the instructions document and the technical project report, including circuit design, calculations, physical implementation, measurement results, and performance analysis.
